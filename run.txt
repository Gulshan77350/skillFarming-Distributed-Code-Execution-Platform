Step 1 — Stop all Node.js processes

pkill -f "node server.js" 2>/dev/null
pkill -f "ts-node" 2>/dev/null
pkill -f vite 2>/dev/null
echo "All Node processes stopped"

Step 2 — Verify ports are free

sleep 2
sudo lsof -i :3000,5001,5003,5004,5005,5006,5173 2>/dev/null


If anything still shows up:

sudo kill -9 <PID>


Step 3 — Stop Docker containers


cd ~/Downloads/distributed-code-execution-platform-main/infra/docker
docker compose down
Step 4 — Verify everything is clean

docker ps
sudo lsof -i :5432,6379,9092,2181

Both should show no output / no running containers.
