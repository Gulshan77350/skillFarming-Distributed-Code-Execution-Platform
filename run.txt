# Platform Run & Teardown Commands

## 🚀 Boot Platform (Single-Command Production Run)
```bash
docker compose -f docker-compose.prod.yml up --build -d
```

Access Points:
- Frontend UI: http://localhost:5173
- API Gateway: http://localhost:3000
- Grafana: http://localhost:3001 (admin/admin)
- Prometheus: http://localhost:9090

## 🛑 Stop Platform & Free Ports
```bash
docker compose -f docker-compose.prod.yml down
```

## 📊 View Container Logs
```bash
# View all logs
docker compose -f docker-compose.prod.yml logs -f

# View execution worker logs
docker logs -f skillfarming-distributed-code-execution-platform-execution-worker-1
```
